# BookChain

A decentralized digital library platform for managing book collections with author rights on Stacks blockchain.

## Features

- Digital book registration with metadata and categorization
- Author ownership verification and rights management
- Reading permissions and access control
- Category-based book discovery system
- Decentralized publishing platform

## Smart Contract Functions

### Public Functions
- `add-book` - Add new book to library
- `update-book` - Update existing book details
- `remove-book` - Remove book from library
- `transfer-book` - Transfer book ownership to new author

### Read-Only Functions
- `get-book-info` - Get book details and metadata
- `get-reading-permission` - Check reading access rights
- `get-total-books` - Get total books in library
- `get-library-stats` - Get library statistics

## Usage

Deploy the contract to create a decentralized digital library where authors can publish their books and manage reading rights while maintaining ownership.
